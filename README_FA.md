# HAPKIDO SCORE — نسخه اولیه اندروید

این پروژه، سورس اولیه برنامه امتیازدهی هاپکیدو است. برای ساخت APK باید Android Studio نصب باشد و Firebase برای اتصال چند گوشی پیکربندی شود.

## ساخت APK
1. Android Studio را نصب کنید.
2. این پوشه را با گزینه Open باز کنید.
3. در Firebase Console یک پروژه بسازید و Android app با شناسه `com.hapkidoscore.app` اضافه کنید.
4. روش ورود Anonymous را فعال و Realtime Database را ایجاد کنید.
5. فایل `google-services.json` را در پوشه `app/` قرار دهید.
6. در Firebase Realtime Database Rules، دسترسی امن برای کاربران واردشده تعریف کنید. برای استفاده واقعی از قوانین عمومی read/write استفاده نکنید.
7. در Android Studio گزینه Build > Build APK(s) را بزنید.

## مهم
این نسخه هنوز APK آماده نصب نیست. کدهای رأی در این نمونه ثبت می‌شوند، اما منطق شمارش رأی اکثریت، ثبت تاریخچه و کنترل دسترسی کامل باید پیش از استفاده رسمی در مسابقه تکمیل و آزمایش شود. تا آن زمان، از آن برای داوری رسمی استفاده نکنید.
